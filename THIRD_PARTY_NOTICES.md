# Dependências e marcas

O código desta distribuição utiliza Angular, RxJS, TypeScript, PO UI, FastAPI, Uvicorn, Pydantic, pyodbc e psutil, entre outras dependências diretas e transitivas. Consulte as licenças distribuídas pelos respectivos pacotes. package-lock.json registra a árvore de dependências do frontend; config/requirements.txt registra os requisitos do backend.

Node.js, Python, SQL Server, ODBC Driver, Windows e Git são ferramentas ou plataformas externas, com condições próprias de distribuição e uso.

Protheus e TOTVS são marcas de seus respectivos titulares. Este projeto não é uma distribuição do ERP e não contém o código-fonte do Protheus.

A identidade e os arquivos de marca JP Code Craft identificam a autoria desta distribuição; a licença MIT não concede licença de marca.
